# library-management-system

## Introduction

The Library Management System is a web-based application used to manage books, members, and library activities.

## Features

- Book registration
- Member registration
- Issue books
- Return books
- View available books
- Generate library reports

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

1. Download the project.
2. Open the project folder.
3. Open `index.html` in a browser.

## Usage

1. Log in to the system.
2. Add books and register members.
3. Issue books to members.
4. Record returned books.
5. Generate a report.

## Future Enhancements

- Mobile application
- Cloud database
